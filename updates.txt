# 📁 File Finder — Early Access v0.2

**v0.2 IS HERE! 🚀**

We’ve just pushed a brand-new update to **File Finder**, bringing new commands, improved search, longer timeouts, and some UI polish!

## 🆕 New Commands

### 🎲 `/random`

Get a **random Roblox `.rbxl` file** from the repository.
Not sure what to look for? Let File Finder pick for you!

### 📊 `/stats`

View **File Finder's bot and repository statistics** in one place.

### 🔥 `/trending`

See the **most searched queries during the current session** and find out what everyone else is searching for.

## ⚡ Improvements

### 🔎 Enhanced File Search

The `/find` system has been improved to make searches **faster, more accurate, and better at finding matching `.rbxl` files**.

### ⏱️ Longer Timeout

The `/find` timeout has been increased from **60 seconds → 2 minutes** when displaying up to **20 files**.

You now have more time to browse through the results without the command timing out on you.

### ✨ UI Polish

File Finder's interface has received a fresh coat of paint with various **UI improvements and visual polish**.

...Although, with every UI improvement comes at least one bug. 💀

## 🚀 More Coming Soon

This is only **v0.2** — there's still plenty more planned for File Finder.

Expect **more features, improvements, and new commands** in future updates.

Thank you to everyone using File Finder during **Early Access** and helping us improve it! ❤️
